# Add two token usage lists (internal)

Add two token usage lists (internal)

## Usage

``` r
add_usage(x, y)
```

## Arguments

- x, y:

  Usage lists from
  [`chat_usage()`](https://n8layman.github.io/ecoextract/reference/chat_usage.md),
  or NULL when no call was made

## Value

Element-wise sum, or NULL if both are NULL
